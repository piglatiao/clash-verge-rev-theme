## 安装（30 秒）

1. 打开 Clash Verge Rev → **设置** → **外观** → **自定义 CSS**
2. 进入喜欢的主题文件夹，打开想要的档位 CSS，**全选复制，整段粘贴**
3. 立即生效；想换档位，替换粘贴内容即可

## 想用自己的壁纸？

主题壁纸都是 base64 内嵌的（无外链、离线可用）。想换图：准备一张 1600px 宽左右的 JPG，转成 base64，替换 CSS 里 `data:image/jpeg;base64,……` 那一串即可。
