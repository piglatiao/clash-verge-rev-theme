## 安装（30 秒）

1. 打开 Clash Verge Rev → **设置** → **外观** → **自定义 CSS**
2. 进入喜欢的主题文件夹，打开想要的档位 CSS，**全选复制，整段粘贴**
3. 立即生效；想换档位，替换粘贴内容即可

## 三档怎么选

| 档位 | 观感 | 适合 |
|---|---|---|
| **ultra** | 纯透明，零模糊 | 壁纸本身干净，想完全看清画面 |
| **high** | 轻微磨砂 | 壁纸细节多，想让卡片后有柔和虚化 |
| **normal** | 磨砂最重、文字最清晰 | 壁纸对比强或长期盯屏 |

## 用 AI 自己做主题

手里有张喜欢的图，想让它变成自己的主题？本仓库自带一个 **AI skill**，装好后对 AI 说一句话就行——
AI 会分析配色、起名、生成三档 CSS、渲染预览、写文档，最后逐档自检。

### 1. 安装

把 [`skills/clash-verge-theme-maker/`](skills/clash-verge-theme-maker/) 整个文件夹复制到你的 skill 目录：

| 客户端 | 放到哪 |
|---|---|
| WorkBuddy | `~/.workbuddy/skills/` |
| Claude Code | `~/.claude/skills/` |
| 其他支持 SKILL.md 的 AI | 对应的 skills 目录 |

> 想分享给别人？把那个文件夹打个 zip 发过去，对方解压到同一目录即可。

然后装两个依赖：

```bash
pip install Pillow      # 必须：压缩并内嵌壁纸
# Chrome 可选：用来渲染预览图，没有也能出 CSS，只是不生成预览
```

### 2. 说一句话

```
用这张图做个 Clash Verge 主题：~/Pictures/我的猫.jpg
```

一次给多张也行：

```
把这 5 张图各做一套主题，输出到 themes/
```

### 3. 它会做什么

1. 读图取色 —— 主色取自画面最稳的色块，亮部同色相提亮，文字取最深暗部
2. 起名 —— 按本合集的「四字中文 + 英文驼峰」规范，如 `午后橘猫 CatNap`
3. 生成 **ultra / high / normal** 三档 CSS，壁纸 base64 内嵌
4. 渲染三张预览图，写主题 README，追加根 README
5. 逐档自检（白雾透明度、模糊强度、渐变、溢出），不通过会直接报错

产出结构和本合集完全一致，做完直接能用。

### 4. 想自己微调配色

配色都写在 `spec.json` 里，最小只需要图片路径 + 一个主色，其余自动推导：

```json
{
  "out": "themes",
  "themes": [
    {"src": "我的猫.jpg", "zh": "午后橘猫", "en": "CatNap", "primary": "#C08040"}
  ]
}
```

```bash
python skills/clash-verge-theme-maker/scripts/build_theme.py --spec spec.json --out themes
python skills/clash-verge-theme-maker/scripts/verify_theme.py --dir themes/cat-nap
```

完整字段、命名规范与常见坑见 [设计指南](skills/clash-verge-theme-maker/references/design-guide.md)；
类名与档位基线见 [CSS 类名文档](docs/css-classnames.md)。

### 5. 做完欢迎投稿

做出来觉得不错，欢迎 PR 加进本合集，见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 想用自己的壁纸？

主题壁纸都是 base64 内嵌的（无外链、离线可用）。想换图：准备一张 1600px 宽左右的 JPG，转成 base64，替换 CSS 里 `data:image/jpeg;base64,……` 那一串即可。
